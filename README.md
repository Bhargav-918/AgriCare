Kisaan Seva AI - Smart Agriculture Management System

Kisaan Seva AI is an AI-powered agriculture web application designed to help farmers make better decisions through crop disease detection, weather forecasting, market price updates, and smart farming recommendations. The platform provides real-time agricultural insights using modern web technologies and cloud services.

Features

-  Crop Disease Detection using AI
-  Upload crop images for instant analysis
-  Real-Time Weather Forecast
-  Market Price Information
-  AI-Powered Farming Recommendations
-  Smart Alerts and Notifications
-  Farmer-Friendly User Interface
-  Firebase Real-Time Database Integration
-  Responsive Design for Mobile and Desktop

Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- TypeScript
- Vite

### Backend & Database
- Firebase Authentication
- Firebase Firestore
- Firebase Hosting

### AI & APIs
- Gemini AI API
- Crop Disease Detection API
- Weather API
- Market Data API
